01 / The premise

Build the biography like an object.

Tatlin moved between painting, sculpture, architecture, costume, and flight. A neutral chronology would flatten that range. The publication instead uses construction as its organising idea: every spread feels assembled, tensioned, and set in motion.

Editorial decisionLet the page behave like Tatlin’s work—structural, spatial, and never static.

02 / The visual system

One grammar. Many kinds of work.

A narrow display face creates urgency; a quieter text face carries longer reading. Red marks the active idea, black builds structure, and fine diagonal lines connect otherwise different image types into one recognisable language.

LINE / MOVEMENT

The line crosses the gutter to turn separate pages into one composition.

03 / Editorial rhythm

A sequence of compression and release.

Dense image-led spreads alternate with quieter pauses. That cadence keeps a long art-historical narrative readable while allowing major works—the Monument, Letatlin, the counter-reliefs—to arrive with visual weight.

04 / The range

The system bends without breaking.

The same components support portraiture, archival photography, object studies, diagrams, and full-bleed art. Consistency comes from relationships—not from forcing every spread into one template.

05 / The outcome

A complete editorial object with a point of view.

The finished academic publication demonstrates a coherent cover-to-colophon system, expressive typography, disciplined image sequencing, and the ability to give varied historical material one contemporary voice.
